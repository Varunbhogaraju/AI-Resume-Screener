# AI Resume Screener 

An AI-powered application that analyzes resumes and matches candidates with job requirements.

### Tech Stack
- **Frontend:** React, Vite
- **Backend:** Python, FastAPI
- **Database:** SQLite
- **AI Integration:** OpenRouter API

### Features
- Resume parsing and analysis
- AI-powered candidate matching
- Candidate and job management
- REST API integration

### Run Locally
1. Install backend dependencies.
2. Configure `OPENROUTER_API_KEY` and `JWT_SECRET_KEY` in `.env`.
3. Start the FastAPI backend.
4. Run the frontend using `npm install` and `npm run dev`.
